# Tejaswini Medandrao — Personal Portfolio

A responsive and interactive personal portfolio website built to showcase my education, skills, projects, achievements, research interests, and technical journey.

The portfolio combines a clean professional layout with a game-inspired interactive experience to make exploring the website more engaging.

## 🌐 Portfolio Overview

The website includes:

- Personal introduction and profile
- About Me section
- Education
- Technical skills
- Projects
- Experience and achievements
- Certifications and activities
- Contact form
- Interactive project filtering
- Theme switching
- Game Mode
- XP and level progression
- Animated visual effects
- Responsive design for desktop, tablet, and mobile

## ✨ Features

### 1. Interactive Home Section

The landing section introduces me and provides quick navigation to important parts of the portfolio.

It includes an interactive visual style with animated elements and a game-inspired interface.

### 2. About Me

Contains information about my background, education, interests, and areas of focus.

My current interests include:

- Artificial Intelligence
- Machine Learning
- Data Analytics
- Software Development
- Healthcare Technology
- Research
- Open Source

### 3. Skills

Technical skills are organized into different categories including:

- Programming
- Web Development
- Databases
- Data & Machine Learning
- Development Tools
- Other Technical Skills

### 4. Projects

Projects are presented as interactive cards.

Projects can be filtered based on categories such as:

- All Missions
- AI / ML
- Web / Full Stack
- Security

This allows visitors to quickly explore projects relevant to their interests.

### 5. Game Mode

The portfolio includes an optional Game Mode that changes the visual experience and adds interactive elements.

Visitors can explore the portfolio while earning XP through different interactions.

### 6. XP and Level System

The website includes a simple progress system.

Users can gain XP by interacting with different parts of the portfolio.

Examples include:

- Exploring projects
- Discovering skills
- Changing the theme
- Activating Game Mode
- Submitting the contact form

The interface updates the user's current XP and level dynamically.

### 7. Theme Switching

The website supports theme switching for a different visual experience.

The selected theme is stored using browser local storage so the preference can remain after refreshing the page.

### 8. Contact Form

A contact form is included for visitors who want to get in touch.

The form validates:

- Name
- Email
- Topic
- Message

Invalid inputs display appropriate feedback, while successful submission displays a confirmation message.

### 9. Responsive Design

The portfolio is designed to work across different screen sizes.

It supports:

- Desktop
- Laptop
- Tablet
- Mobile

The layout automatically adjusts using CSS media queries, Flexbox, Grid, and Bootstrap's responsive utilities.

### 10. Accessibility

Accessibility has been considered throughout the website.

Features include:

- Semantic HTML structure
- Descriptive labels
- ARIA attributes where required
- Keyboard focus states
- Readable contrast
- Responsive layouts
- Reduced-motion support
